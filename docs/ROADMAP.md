# Roadmap

## Foundation

- Documentation, ADRs, package build, semantic theme, primitives, versioned registry, four initial blocks, catalog, tests, CI, and integration guidance.

## After integration feedback

- Validate the package in NUMU Admin and one independent website.
- Stabilize proven block contracts and publish through an approved private channel.
- Add migration tooling and visual regression baselines.
- Consider framework adapters only when consumers demonstrate a shared need.

## Deferred

Full page builder, backend APIs, persistence, authentication, publishing, forms engine, navigation builder, advanced header/footer, galleries, pricing, testimonials, FAQ, team blocks, advanced animation, and AI generation are outside the foundation.
